# **Climate Hazard Monitoring Dashboard for Early Warning Decision Support**

### **Overview**

This project demonstrates the development of an interactive geospatial dashboard for monitoring climate hazards and supporting early warning decision-making.

The dashboard integrates environmental, climatic, and geospatial datasets to visualize risk patterns, support preparedness planning, and enhance data-driven decision-making.

# 

### **Dashboard Components**

* Interactive Map
* Homa Bay Boundary
* Road Network
* Settlements
* Vegetation Monitoring Layers

# 

### **Indicators**

* Mean NDVI (0.346)
* Maximum NDVI (0.933)
* Vegetation Status (Moderate)

# 

### **Applications**

* Climate Monitoring
* Early Warning Systems
* Disaster Risk Reduction
* Decision Support

# 

### **Technologies**

* ArcGIS Online
* ArcGIS Dashboards
* QGIS
* Google Earth Engine
* GIS \& Remote Sensing

# 

### **Results**

The dashboard provides an interactive platform for visualizing climate-related indicators and geospatial datasets to support risk analysis and decision-making.
